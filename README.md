# MyRepublic Purwokerto Landing

Create a premium responsive landing page for MyRepublic Purwokerto.

IMPORTANT: Follow the reference design I provided as closely as possible — same layout structure, spacing, visual hierarchy, typography style, card composition, and overall rhythm. Only replace the content/branding with MyRepublic.

Include:

Navbar + CTA

Hero section focused on MyRepublic Purwokerto

Internet package section

Coverage Checker with search/address input + map UI placeholder, designed for future backend/Maps API integration

Benefits/features

Strong conversion CTA

Footer

Design: modern, premium, clean, bold, trustworthy, mobile-first.

ANTI AI-SLOP: No generic AI landing-page template, no text-left/image-right hero, no excessive glassmorphism, random gradients, excessive rounded cards, unnecessary icons, fake 3D elements, or excessive animations. Make it feel human-designed and production-ready.

Use React + TypeScript + Tailwind CSS. Keep components clean and reusable. Frontend only; do not create fake coverage data.
